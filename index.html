Help - Getting a file to inspectv1.0.0

How to get a PAR
A) VIA FAT CLIENT OMW
  1. Add the required object to a project.
  2. Hit the Get button to get the latest specs.
  3. Click Save and choose a suitable location to save the PAR file.
B) VIA OMW WEB
  1. Add the required object to a web OMW project.
  2. Select the object from the project's Project Objects tab, then under More Row Actions choose Export to download the PAR file.
How to get an ER extract
A) VIA REPORT / FORM DESIGN AID
  1. From the event rules window of any control or section, click the Print icon.
  2. Set Print Scope to Report, and select all the options under Print ER options to get the complete report logic.
  3. Under Destination, choose a file name and location, then click OK to write the ER extract.
B) VIA P95110
  1. From the fat client, type P95110 in fast path to open Search Event Rule Objects.
  2. Select the object type (Application/Report), search by object name, then choose Print ER from Row Exit - this opens the complete event rules in a text editor.
  3. Go to File → Save As and save it to a preferred folder to get the ER extract.

Readmev1.0.0

What it does & Overview
The What it does tab gives a fully derived, plain-English explanation of the object - nothing hard-coded per object. It covers what the object is for, an "In plain terms" call-out when the object shows a staging/interface pattern, what processing options steer, and notable developer comments with jump links.

The Overview tab shows object-wide statistics: table I/O counts, business function calls, and report interconnects.
Sections / Execution order / Data selection
Sections lists every section (UBE) or form/control (Application) with its type, business view, and line count. Execution order and Data selection are UBE-only tabs showing run order and the object's data selection criteria - they're hidden automatically for Applications, where they don't apply.
Event Rules tab
The deepest tab in the app. Each section/control is collapsible, and shows:
  • Line numbers - sequential, exactly like a real ER dump. Lines that are parameters of a table I/O or business-function call inherit the number of the statement above them, since they're part of the same logical step.
  • Sticky section header - stays pinned to the top while you're scrolled deep into a long open section.
  • Hover for If context - hover any line to see the nearest enclosing If condition (and the full nested path for deeper blocks) pinned to the top of the screen.
  • Search, Open all / Close all, and Go to line # to jump straight to any line number.
  • Download this section or the whole listing as text.
Variables tab
Every operand in the object that carries a standard JDE prefix (VA, PO, SV/SL, BC/PC/TC, RI/RV/RC, TV, GC, and FI/FC for Applications) is catalogued and grouped by type. Click a variable to see every place it's used - each occurrence shows the exact line, a tag naming the table I/O statement or business function it's a parameter of, and a link that jumps straight to that precise line. A search box narrows the list to matching names.
Find text / Tables / External calls / Processing options
Find text full-text searches every line of ER, with clickable jumps. Tables lists every table touched with read/insert/update/delete counts. External calls shows business functions called and (UBEs) other reports launched. Processing options (UBE only) lists every option in use with a best guess at what each steers.
Ask tab
Ask plain-English questions - "What does this do?", "What uses a table?", "Where is a variable set?", "Which business functions does it call?" - or tap a suggested card. Cards and answers adapt automatically depending on whether you loaded a UBE report or an Application. Every answer is grounded in the parsed object, and any section or line it references is clickable.
UBE reports vs. Applications
The app recognises both JDE object types automatically. Applications (object names typically start with P) are organised by Forms → Controls instead of Sections, get extra FI/FC operand prefixes in the Variables tab, and hide the Execution order and Data selection tabs since they're not meaningful for interactive controls. Ask tab cards and wording adjust to match.
Multiple files & printing
Upload more than one independent object at once and every one of them stays available - click any filename in the loaded-files panel to switch the active view. Print / Save as PDF opens your browser's print dialog with the filename pre-set, with an option to include the full event rules listing.
Tips & tricks
  • Hover any line in Event Rules to see which If it's nested under, pinned to the top of the screen.
  • Type a number into Go to line # to jump anywhere instantly - the numbers match what you'd see in a real ER dump.
  • Jumped away from Variables, Find, or Ask into Event Rules? Click the ← Back pill (bottom-left) to return to your exact scroll position, not just the top of the tab.
  • Uploaded more than one object? Click any filename above Print/Save as PDF to switch between them.
  • Click a variable's table-I/O or business-function tag in the Variables tab to see exactly which call it belongs to.
  • A floating ↑ Top button appears once you scroll down, for a quick trip back to the top of the page.
